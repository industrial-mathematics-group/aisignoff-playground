# Hands-on files

Each workshop participant adds one file here, named after themselves (`jane-doe.md`), in their own pull
request: see [exercise 1](../04-hands-on.md#exercise-1--your-first-pull-request-10-min).
[example-person.md](example-person.md) shows what one looks like.

This repository is public: only put things here that you're happy to have on the internet.
