# Workshop: GitHub and AI signoff

**Thursday, 19 November 2026 · about 75 minutes · everything in the web browser, no command line**

This folder is the whole workshop: the "slides" are these pages, the demo happens in this repository, and at
the end you will have opened, checked and merged a pull request yourself.

| | Part | Time | What happens |
|---|---|---|---|
| 1 | [The mental model](01-mental-model.md) | 10 min | Repository, commit, branch, pull request, merge, as pictures |
| 2 | [Live demo](02-live-demo.md) | 20 min | Change a file in the browser, open a pull request, watch the checks go red and green, merge |
| 3 | [AI signoff](03-aisignoff.md) | 15 min | Why we declare AI use, the G · H · A levels in plain words, who is responsible, the @signoff assistant, the report |
| 4 | [Hands-on](04-hands-on.md) | 20 min | Everyone adds a file, declares it in a pull request and merges it |
| 5 | [Releases and DOIs](05-zenodo.md) | 10 min | Zenodo: every GitHub release gets a DOI, a badge and a citation |

**Take home:** the [cheat sheet](cheat-sheet.md) ([printable PDF](cheat-sheet.pdf)).

## Before you come

1. **A GitHub account.** Sign up at <https://github.com/signup> if you don't have one, and send your user name
   to Pascal so you can be given access to this repository.
2. **A browser.** That's all. [GitHub Desktop](https://desktop.github.com/) is a nice optional app for later
   (it works with folders on your computer), but we won't need it.

## Ground rules for this repository

- **It is public.** Anyone on the internet can read it. Don't upload unpublished results, data about people,
  passwords or anything confidential, here or into an AI tool.
- **It is a playground.** Nothing you do here can break anything that matters. Try things out.
- **You are responsible for what you merge**, whoever or whatever wrote it. That's the one idea behind AI signoff.
